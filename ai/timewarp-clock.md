# Time Warp and Clock

TimeWarp.py performs a one-shot warp to the earliest next Trigger, Arr, Dep, or clock-held ActiveTrain. It aborts if a train is running. Functions: ReadMemStr, ReadMemBool, ParseTime, MinutesSinceMidnight, CircularEarlier, FindNextWorkingFromTimetable, SnapshotActiveTrains, AnyTrainRunningNow, FindEarliestActiveTrainTimedStart. Memories: CURRENTTIMETABLE, CURRENTTIME, DAYOFWEEK, ALLOWTIMEWARP. TimeWarp.py reads profile:timetable/<name>.csv with csv.DictReader delimiter tab. It uses jmri.InstanceManager.getDefault(jmri.jmrit.dispatcher.DispatcherFrame) with getActiveTrainsList, getStatus, getDepartureTimeHr, getDepartureTimeMin, getDelayedStart, and jmri.jmrit.dispatcher.ActiveTrain constants RUNNING, WORKING, PAUSED, READY, STOPPED, WAITING, TIMEDDELAY. It uses jmri.InstanceManager.getDefault(jmri.Timebase) with setTime and getTime. It calls execfile on profile:jython/retryEnqueuedWorkings.py. It sets ALLOWTIMEWARP to false, sets CURRENTTIME to formatted time, sets DAYOFWEEK to next day when the warp crosses midnight.

TimeWarpChecker.py is a startup script. Class CheckActiveTrains extends java.util.TimerTask with method run and __init__(startMs, graceMs). Timer schedule is 0 ms delay and 1000 ms period through java.util.Timer. Constant TIMEWARPCHECKER_STARTUP_GRACE_MS = 30000 keeps ALLOWTIMEWARP False for the first 10 seconds after the script starts, so input hardware that reports active while it powers up cannot warp the clock during JMRI start-up. It then sets Memory ALLOWTIMEWARP to True or False through TASBeanLookup.ProvideMemoryBySuffix. It reads DispatcherFrame ActiveTrain list and checks status WAITING and TIMEDDELAY with getDepartureTimeHr, getDepartureTimeMin, getDelayedStart.

TASFastClockStartup.py is a startup script. It persists fast-clock time and Memory DAYOFWEEK on shutdown and restores on start when saved-startup is enabled. Constants: IMFastClockUseSavedStartup = TASFASTCLOCKUSESAVEDSTARTUP, IMFastClockSavedTime = TASSAVEDFASTCLOCKTIME, IMDayOfWeek = DAYOFWEEK, STATE_FILE = profile:jython/config/TASFastClockState.txt. Functions include GetLiveOnlyMode, GetJvmFlag, SetJvmFlag, GetRegisterOnlyMode, GetShutDownManager, LoadState, SaveState, PersistUseSavedStartupChoice, SyncSavedStartupChoiceToMemory, GetTimebase, UseSavedStartupEnabled, FormatDateToClockText, ParseClockTextToDate, LoadSavedClockText, SaveSavedClockText, LoadSavedDayOfWeek, SaveSavedDayOfWeek, NormalizeDayOfWeek, RegisterShutdownTaskOnce, EnsureShutdownTaskRegistered, ApplySavedStartupTimeOnce. Class PersistFastClockTask extends jmri.implementation.AbstractShutDownTask with method run. State file keys are useSavedStartup=, clockText=, dayOfWeek=. JMRI APIs: jmri.InstanceManager.getDefault(jmri.ShutDownManager), jmri.InstanceManager.getDefault(jmri.MemoryManager), jmri.InstanceManager.getDefault(jmri.Timebase) with getTime, userSetTime, setTime, getIsInitialized.
