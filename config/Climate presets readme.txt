Column meanings 

name — preset key you’ll refer to from code (e.g., SouthWales_EarlySep).
mean_cloud — baseline cloud fraction (0–1).
long_amp — slow (multi‑hour/day) undulation amplitude (0–1 scale).
short_amp — faster (diurnal-ish) undulation amplitude (0–1 scale).
noise_pp — peak‑to‑peak micro‑variability (e.g., 0.04 → ±2% around zero).
p_clear / p_overcast — daily probabilities of a clear/overcast “event” (rest = none).
event_clear_strength / event_overcast_strength — how strongly events push cloud down/up (typical 0.3–0.55).
event_duration_min / event_duration_max — event duration range in minutes (e.g., 180–540 = 3–9h).
clear_ceiling — max cloud fraction permitted during a clear event (e.g., 0.20 = ≤20%).
